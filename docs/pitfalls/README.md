# 长期避坑知识库

## 用途

这里记录项目开发、修复、测试、部署和排障中已经由项目文件、实际命令、Git 历史或当前对话证实的可复用风险。它是规则文件之外的具体经验库，不能替代测试或真机验收。

## 每次任务的读取规则

1. 开发、修复、测试、部署或排障前，先读取项目根目录 `AGENTS.md`。
2. 再读取本 README 和与任务模块相关的避坑文件。
3. 将相关条目的验证方式纳入本次工作；不适用的条目要说明原因。

## 写入规则

- 任务收尾前检查是否发现新坑；新坑按模块追加到已有文件，无法合理分类时写入 `general.md`。
- 只记录可追溯证据，不编造根因、报错、数值或验证方式。信息不足时标注“信息不全，待人工补充”或“以下为基于现有证据的推测”。
- 不写入密钥、Token、账号密码、隐私数据、生产配置全文或完整敏感日志。
- 历史回填只做一次；以后采用增量追加，并更新下面的文件索引。

## 条目格式

每条避坑使用 Markdown 二级标题，并包含以下字段：

- **现象**
- **根因**
- **正确做法**
- **验证方式**
- **禁止事项**
- **相关文件或命令**
- **适用范围**
