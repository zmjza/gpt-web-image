## 已确认选择

- 同时支持自然语言自动触发和 `$gpt-web-image` 显式调用。
- 支持文字生图、参考图改图和连续修改。
- 多图不足时在同一会话补足，最多 3 轮。
- 明确请求直接执行，存在歧义时才询问。
- 多图修改目标不明确时先编号并让用户选择。
- 图片和任务记录永久保留；脱敏诊断资料保留 7 天。
- Skill 名称为 `gpt-web-image`，显示名为“GPT 网页生图”。
- 首版平台为 macOS ARM64 与 Windows x64。

## 本轮整理结论

- 页面删除是用户主动的二次确认删除；Codex/自动任务仍永远禁止删除。
- 备份按用户确认不加密，必须显示敏感数据警告并限制在本机。
- 浏览器采用全局单专用 Chrome 进程和独立生图任务标签页。
- 会员检测必须通过多信号解决，技术失败禁止启用，不把未知状态视为可用。
