# 结构异常与诊断升级

上级：[[_06-生成监控]]
下级：无
依赖：[[语义定位与结构兼容]]、[[日志脱敏与诊断保留]]

---

## 场景

关键元素缺失、多候选冲突、responseAnchor 丢失或页面出现未知拦截。

## 触发

语义定位无法满足关键不变量，或状态证据互相矛盾。

## 逻辑

停止提交、点击和下载，保存脱敏语义快照、局部 DOM 摘要、截图、控制台错误和 Trace 引用，发出 `structure_changed` 或 `result_uncertain`，必要时切换可视模式供检查。

## 状态 / 边界

诊断不得包含 Cookie、认证头、密码或完整私密会话。不能用坐标盲点继续；结构异常不是普通网络错误，禁止自动重复提交。
