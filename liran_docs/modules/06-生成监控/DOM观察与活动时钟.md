# DOM 观察与活动时钟

上级：[[_06-生成监控]]
下级：无
依赖：[[回复区域绑定与防串图]]

---

## 场景

生成过程中页面会逐步插入占位、文本、图片和控件，需要事件驱动观察而不是固定等待。

## 触发

绑定回复区域建立后安装 MutationObserver，并在恢复时重新安装。

## 逻辑

观察子树、属性和图片资源变化，将相关变化合并为递增 DOM 版本并刷新 lastActivityAt；过滤无关动画、时间显示和页面其他区域噪声。

## 状态 / 边界

DOM 变化只表示活动，不直接表示成功。观察器失效、页面导航或 anchor 脱离时必须重新绑定或进入结构异常。
