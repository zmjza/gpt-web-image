# 多信号判定与超时

上级：[[_06-生成监控]]
下级：无
依赖：[[DOM观察与活动时钟]]、[[图片发现与稳定判定]]、[[状态机与迁移]]

---

## 场景

页面可能显示加载控件、部分图片、错误提示或静止但未完成的回复。

## 触发

DOM 活动、语义控件变化、图片候选、网络状态或 watchdog 定时检查。

## 逻辑

综合生成活动标志、错误/重试语义、图片加载、回复稳定和网络旁证推进状态。启动 60 秒、无活动 240 秒、硬上限 1200 秒；有相关活动仅刷新无活动计时。

## 状态 / 边界

固定时长到达不能直接判成功。429、5xx、内容拒绝、登录失效和下载失败必须分类；重试策略只适用于明确的可恢复错误。
