# 状态机与迁移

上级：[[_06-生成监控]]
下级：无
依赖：[[回复区域绑定与防串图]]、[[TaskRecord与任务ID]]

## 场景

长时间网页任务需要让脚本、Codex、恢复逻辑和最终状态使用同一语义。

## 触发

页面、任务、下载、取消或超时产生新证据。

## 逻辑

使用显式迁移表约束 `initializing/needs_login/ready/submitting/submitted/queued/generating/partial/stabilizing/downloading/validating/succeeded/partial_success/failed/timed_out/cancelled/recovering/needs_human_verification/structure_changed/result_uncertain`。

## 状态 / 边界

终态不可被普通事件覆盖。成功必须来自文件校验证据；恢复、取消和不确定状态不得被折叠成失败或成功。
