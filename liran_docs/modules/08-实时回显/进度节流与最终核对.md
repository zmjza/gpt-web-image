# 进度节流与最终核对

上级：[[_08-实时回显]]
下级：无
依赖：[[JSONL事件协议]]、[[逐张实时回显]]、[[数量记忆与补图]]

---

## 场景

DOM 活动频繁，但用户只需要状态变化和真实结果；终态还需核对事件与文件。

## 触发

重复状态、心跳、补图决策或任务终止。

## 逻辑

相同状态只在计数变化、关键消息变化或心跳间隔到达时输出。终态读取 task.json，核对唯一合格 ImageResult、已发 `image_ready`、目标数量和失败项后生成摘要。

## 状态 / 边界

最终成功数不能由网页图片数直接得出。事件缺失、文件缺失或计数不一致时进入结果不确定并报告差异。
