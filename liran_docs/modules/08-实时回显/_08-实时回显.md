## 职责

将任务状态和合格图片编码为递增 JSONL 事件，指导 Codex 在当前任务未结束时逐张显示本地图片，并在终态核对数量。

## 对外提供

- 版本化 ProgressEvent、`image_ready`、终态摘要和退出码映射。
- 去重、节流和最终清单核对规则。

## 关键说明

图片必须在校验后立即回显，不能等整批完成。事件顺序由 taskId + seq 保证；同一 resultId 或 SHA-256 不得重复回显。

## 当前实现

CLI 已输出递增 JSONL，唯一图片校验后立即产生 `image_ready`，Skill 约定立即用绝对路径渲染。完整 CLI Chrome 夹具证明两张图片事件均早于 `terminal`；真实 Codex 对话渲染仍待 T40。
