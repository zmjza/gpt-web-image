# 逐张实时回显

上级：[[_08-实时回显]]
下级：无
依赖：[[JSONL事件协议]]、[[格式校验与去重]]、[[PNG预览与输出目录]]

---

## 场景

批量生成仍在继续时，用户希望先看到每张已成功拉取的图片。

## 触发

校验器创建新的唯一 ImageResult 并发出 `image_ready`。

## 逻辑

Codex 立即使用 previewPath 或 originalPath 的绝对路径渲染 Markdown 图片，并报告 `X/N`；同时保留文件路径供后续编辑。宿主确认消费后记录 resultId/哈希。

## 状态 / 边界

不能等待终态统一显示，不能只输出路径或“成功”文本。未校验文件、临时文件和重复哈希不得回显；后续失败不撤销已成功图片。
