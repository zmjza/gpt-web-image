# PNG 预览与输出目录

上级：[[_07-图片交付]]
下级：无
依赖：[[格式校验与去重]]、[[系统目录与路径规范]]

---

## 场景

原图需要稳定存档，而某些格式可能无法由 Codex 宿主直接渲染。

## 触发

原图校验通过，或宿主兼容规则要求生成预览。

## 逻辑

按日期/taskId 创建 `original/edited/preview/diagnostics` 等受控目录；原图保持不变，必要时以可靠解码器生成 PNG previewPath，均写入 ImageResult。

## 状态 / 边界

预览不能替代或覆盖原图。路径名需跨平台安全；无工作区时回退到系统 Pictures，诊断目录与永久图片目录必须分离。
