# 原图下载与临时文件

上级：[[_07-图片交付]]
下级：无
依赖：[[图片发现与稳定判定]]、[[系统目录与路径规范]]

---

## 场景

稳定图片需要获取网页提供的原始文件并安全写入本地。

## 触发

图片候选首次达到稳定状态。

## 逻辑

优先同时等待 Playwright download 事件并点击当前媒体卡对应的下载入口；不可用时只读取该媒体卡已经暴露的本次原始资源。写入任务 `.partial` 临时目录，完成后交给校验器，并保存下载方式和来源 provenance。

## 状态 / 边界

禁止使用截图作为交付。资源回退不得请求未在页面暴露的私有端点，也不得使用任意 `currentSrc`；下载卡、媒体卡和响应锚点不能唯一对应时安全失败。失败保留原因并可在明确可恢复时有限重试。
