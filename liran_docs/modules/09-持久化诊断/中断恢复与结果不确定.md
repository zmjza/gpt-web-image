# 中断恢复与结果不确定

上级：[[_09-持久化诊断]]
下级：无
依赖：[[task-json持久化]]、[[提交确认与幂等保护]]、[[回复区域绑定与防串图]]

---

## 场景

Codex、Node 或 Chrome 在提交后中断，用户希望继续而不是重复消耗额度。

## 触发

resume 命令加载非终态 TaskRecord，或启动时发现孤立任务。

## 逻辑

检查 schema、文件、会话 URL、已确认提交、responseAnchor 证据和已有结果；可唯一恢复时重建观察器，无法确定是否提交或绑定时进入 `result_uncertain`。

## 状态 / 边界

恢复默认只读检查，不自动重新提交。原会话不可用时明确说明丢失的上下文；用户另行决定前不能创建替代任务。
