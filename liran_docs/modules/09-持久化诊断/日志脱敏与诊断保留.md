# 日志脱敏与诊断保留

上级：[[_09-持久化诊断]]
下级：无
依赖：[[结构异常与诊断升级]]、[[系统目录与路径规范]]

---

## 场景

网页结构、网络、下载或恢复异常需要留下足够证据供修复。

## 触发

结构异常、结果不确定、非预期退出、下载/校验失败或显式诊断命令。

## 逻辑

保存时间、taskId、状态、错误码、脱敏语义快照、局部 DOM 摘要、截图路径、Trace 路径和版本信息；过滤 Cookie、Authorization、token、密码字段及敏感查询参数。

## 状态 / 边界

默认不保存完整页面 HTML、完整网络头或用户账号信息。诊断资料位于独立目录，保留期 7 天。
