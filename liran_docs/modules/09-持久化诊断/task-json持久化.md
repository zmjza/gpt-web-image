# task.json 持久化

上级：[[_09-持久化诊断]]
下级：无
依赖：[[系统目录与路径规范]]、[[TaskRecord与任务ID]]

---

## 场景

任务可能持续数分钟并经历浏览器切换、取消或进程中断，需要可恢复事实来源。

## 触发

任务创建、重要状态迁移、提交确认、图片成功、补图、取消和终态。

## 逻辑

以版本化 TaskRecord 写临时文件、fsync/关闭后原子替换正式 task.json；保留最近可信状态、会话 URL、结果和事件序号。

## 状态 / 边界

不能持久化 Cookie、令牌、认证头或密码。写入失败必须停止进一步不可逆动作，避免网页状态与本地事实继续分叉。
