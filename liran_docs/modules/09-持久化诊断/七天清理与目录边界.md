# 七天清理与目录边界

上级：[[_09-持久化诊断]]
下级：无
依赖：[[日志脱敏与诊断保留]]、[[系统目录与路径规范]]

---

## 场景

诊断截图、快照和 Trace 不应永久占用空间，但图片和 task.json 必须保留。

## 触发

任务启动后的低优先级清理或显式 cleanup 命令。

## 逻辑

枚举专用 diagnostics 根目录内超过 7 天的允许类型，规范化 realpath，验证仍在根目录且非越界符号链接后删除；输出删除/跳过/失败报告。

## 状态 / 边界

不得遍历或删除 original、edited、preview、task.json、Profile、配置或根目录外文件。时间与路径不确定时必须跳过。
