# 可控网页夹具

上级：[[_10-验证发布]]
下级：无
依赖：[[语义定位与结构兼容]]、[[状态机与迁移]]、[[图片发现与稳定判定]]

---

## 场景

网页状态机、下载和结构改版需要可重复测试，不能每次消耗真实 Plus 额度。

## 触发

集成测试和 Windows CI。

## 逻辑

本地夹具模拟输入区、用户/助手 turn、排队、占位图、逐张图片、下载、错误、验证码、429/5xx、DOM 变体、静止超时和恢复；使用测试图片验证逐张事件。

## 状态 / 边界

夹具用于验证控制逻辑，不得伪装成真实 ChatGPT 通过证据。网络 mock 只能在测试夹具环境启用。
