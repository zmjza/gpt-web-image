## 场景

核心规则需在不访问真实 ChatGPT 的情况下快速、确定性验证。

## 触发

每个模块 TDD、提交前验证和 CI。

## 逻辑

使用 Node 内置测试覆盖配置、路径、状态迁移、事件 schema、队列、数量、哈希、原子写入、恢复、脱敏和清理；契约测试确保 JSONL、task.json 与 CLI 退出码兼容。

## 状态 / 边界

单测通过不证明真实网页兼容或双平台完成。测试不得包含真实 Cookie、Plus 账号或生产会话。
