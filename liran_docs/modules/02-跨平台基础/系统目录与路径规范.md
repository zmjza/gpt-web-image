## 场景

Profile、配置、任务输出、诊断和安装目标需要在 macOS 与 Windows 上落到正确目录。

## 触发

首次 setup、创建任务、写诊断、安装或清理。

## 逻辑

使用 Node Path 与系统环境解析用户数据目录；有工作区时输出到 `gpt-web-images/{YYYY-MM-DD}/{taskId}`，无工作区时回退 Pictures 专用目录。统一规范化、创建并校验根路径。

## 状态 / 边界

过滤 Windows 非法字符和保留名，处理中文、空格和长路径。禁止写死用户名、盘符或分隔符；禁止让清理目标逃出专用根目录。

## 当前实现

已创建 `src/platform/paths.ts`，实现安全文件名、Windows 保留名过滤、日期/taskId 输出目录和根目录边界判断；中文、空格、保留名、越界、真实临时目录创建和诊断清理测试已通过。Windows 原生路径仍待 T39 CI。
