# 用户级安装与升级

上级：[[_02-跨平台基础]]
下级：无
依赖：[[Chrome探测与能力检查]]、[[Skill元数据与自动触发]]

---

## 场景

用户希望在任意 Codex 项目中使用 Skill，或从仓库升级已有安装。

## 触发

运行跨平台安装命令或升级命令。

## 逻辑

把版本化 Skill 源安装或链接到用户级 Codex 可发现目录，校验 SKILL.md 与 `agents/openai.yaml`，保留 Profile、配置和任务数据，并输出安装目标和发现验证方法。

## 状态 / 边界

不得覆盖不属于本项目的同名目录；升级必须先确认目标归属并支持回滚。Windows 不依赖 WSL 或 Bash；安装失败不得破坏已有可用版本。
