下级：无
依赖：无

---

## 场景

任何命令启动时需要稳定读取 Profile、输出、超时、数量和诊断保留配置。

## 触发

CLI 初始化或用户更新默认数量、路径和超时。

## 逻辑

按内置默认值、用户级配置、命令参数的优先级合并并验证 Config；首次默认数量 1、最大补图 3、启动 60 秒、无活动 240 秒、硬上限 1200 秒、诊断保留 7 天。实现阶段暂定稳定窗口为 1500 毫秒，后续由可控网页夹具验证并可调整。

## 状态 / 边界

配置未知字段和非法范围必须给出明确错误；配置中不得出现 Cookie、密码或令牌。最终配置结构见 [[06-数据字典]]。

## 当前实现

已创建 `src/config/schema.ts` 与 `src/config/load.ts`，实现默认值、配置合并、未知字段拒绝、敏感字段拒绝和范围校验；本地配置单元测试已通过。真实用户级配置目录将在后续跨平台安装任务中接入。
