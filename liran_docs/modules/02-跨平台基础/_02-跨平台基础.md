## 职责

为 macOS ARM64 与 Windows x64 提供统一配置、目录、Chrome 能力检测、安装和升级边界，屏蔽平台差异。

## 对外提供

- 规范化 Config、系统数据目录、Pictures 回退目录和 Chrome 可执行文件位置。
- 原子文件、进程探测和安全路径判断所需平台工具。
- `doctor` 能力报告和用户级 Skill 安装入口。

## 关键说明

Windows 不依赖 WSL；核心命令不能要求 Bash。所有路径必须经 Node Path API 规范化，Windows 文件名需过滤保留名和非法字符。
