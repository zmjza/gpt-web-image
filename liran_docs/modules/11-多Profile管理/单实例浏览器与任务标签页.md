# 单实例浏览器与任务标签页

## 规则

全局只有一个项目专用 Chrome 进程。人工浏览标签页与生图任务标签页分离；任务结束关闭任务标签页，不能结束用户日常 Chrome。项目启动的进程才允许由关闭按钮关闭。

管理页“打开浏览器”只启动/复用项目拥有的 Profile 浏览器，不自动改变 active；“检测状态”可以使用受控后台会话读取登录/会员/Chrome 状态，但不会把该会话显示为手动打开。关闭时先写入 `closing`，成功回写 `closed`，失败回写 `unknown`，并始终释放 BrowserLease 和 Profile 锁。
