# Profile 创建、导入、修改、删除

上级：[[_11-多Profile管理]]
依赖：[[Profile注册表与生命周期]]、[[默认目录与自动扫描]]

## 交互

创建生成新目录和归属标记；导入必须用户选择并确认；修改只允许名称、账号备注和说明；删除弹出路径和认证数据警告，第二次确认后才能删除。

## 禁止

当前启用、浏览器占用或任务运行中的 Profile 不得删除。自动任务、cleanup、升级和恢复不得调用物理删除。

## 本轮隔离验收

- 一次性临时数据根中，页面创建和导入带有效 `.gpt-web-image-profile.json` 归属标记的 Profile 均成功；编辑备注后注册表和页面一致。
- 导入普通 Chrome 目录被拒绝并返回脱敏错误，未注册该目录；真实用户 Profile 未删除、迁移或覆盖。删除能力仍需页面二次确认，自动流程不能构造确认值。
