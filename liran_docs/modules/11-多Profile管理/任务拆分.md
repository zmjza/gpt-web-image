# 多 Profile 管理任务拆分

本文件是 T43–T61 的详细任务卡。T43–T59 已完成内部实现和自动化验证；T60–T61 仍属于 macOS 真机、Windows CI 补充证据和 Windows x64 用户验收阶段。任务状态以每项“完成后状态”和 `liran_docs/09-真机实测.md` 为准。

## T43 ProfileRegistry 模型与原子存储

- 依据文档：[[Profile注册表与生命周期]]、[[06-数据字典]]。
- 涉及模块：`src/profiles/registry.ts`、`src/config`。
- 动作：定义版本化注册表、兼容旧 `profileDir`、原子写入、敏感字段拒绝和 active 唯一性。
- 状态/API：新增 Registry 读写接口；不改变现有生图 API。
- 安全边界：不读取认证数据，不删除 Profile。
- 验证：损坏 JSON、并发写、未知 schema、重复 active 和旧配置迁移测试。
- 完成标准：读写失败可恢复旧文件，旧 Profile 可注册，敏感字段永不落盘。
- 完成后状态：内部测试通过。
- 验收影响：macOS、Windows CI 和后续真机。
