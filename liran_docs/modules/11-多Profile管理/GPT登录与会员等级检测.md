# GPT 登录与会员等级检测

上级：[[_11-多Profile管理]]
依赖：[[首次可视登录]]、[[唯一启用与资格检查]]

## 检测策略

使用同一专用 Chrome 会话，先等待稳定、可交互的 composer，再检查可见账户入口、会员计划文本和可用功能信号，支持中文/英文语义及本地化 `aria-label`/`title`。Plus、Pro、Go 会员已可靠识别时，生图控件暂未完成 hydration 不否定资格；未登录、验证接管、其他会员或技术检测失败仍禁止启用。自动重试和重新导航后仍失败，返回技术失败并禁止启用；不读取邮箱、密码、Cookie 或 Token。

## 任务

关联：T48、T60。验证：T-MP-10。真实会员等级必须在 macOS 真机中记录脱敏证据；魏邦真实网页为 Plus，里燃未登录启用被阻止，回归测试 6/6；0.2.6 对应 Windows CI 已绿色。
