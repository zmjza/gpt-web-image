上级：[[_11-多Profile管理]]
依赖：[[Profile注册表与生命周期]]、[[默认目录迁移与保留]]

## 页面范围

中文响应式页面包含列表、创建/导入/修改表单、启用、检查、打开/关闭浏览器、迁移/保留预检、删除二次确认、备份警告、恢复、加载、空态、占用态、错误态和成功反馈。

## 服务边界

本地服务只绑定 `127.0.0.1`，不需要网页密码，不开放局域网；响应脱敏，不返回认证数据。UI 已通过同源 API 完成业务接线，mock/type 仅保留必要的类型和无数据状态锚点。
