## 职责

在不接管日常 Chrome 的前提下，管理多个专用 Profile、默认目录、唯一启用项、浏览器租约、会员资格、备份和页面操作。

## 安全边界

扫描只识别有效归属标记；自动流程永不删除 Profile；页面删除必须二次确认；未加密备份包含认证数据，不能进入 Git、日志或诊断。

## 2026-08-05 生命周期修复与验收

- 管理服务将启用、检测、打开和关闭拆为独立动作：启用先验证 `logged_in` 与 `plus/pro/go` 并关闭旧项目浏览器；检测只更新资格/Chrome 状态；打开不隐式启用；关闭只操作项目拥有的浏览器并在 `closing` 阶段阻止重复请求。
- 所有浏览器动作都要求 `pathStatus=ok`，统一使用全局 BrowserLease；异常关闭通过 `finally` 释放 lease 和 Profile 锁。默认目录扫描在注册事务提交时再次按规范化路径和名称去重。
- macOS 真实魏邦 Profile 只读检测为 `logged_in / plus`；隔离页面完成创建、导入、编辑、唯一启用和 Chrome 生命周期；真实 Profile 未执行破坏性操作。
