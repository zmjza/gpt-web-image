# 唯一启用与资格检查

上级：[[_11-多Profile管理]]
依赖：[[GPT登录与会员等级检测]]、[[Profile注册表与生命周期]]

## 规则

注册表最多一个 `activeProfileId`。启用前必须检查目录、归属标记、GPT 登录、会员等级和浏览器占用；只有登录且等级为 Plus、Pro、Go 才允许启用。

启用与检测不共用页面语义：检测只更新资格和 Chrome 状态，不改变 active；启用通过资格检查后，如旧 Profile 有项目浏览器则先关闭旧浏览器，再原子切换唯一 `activeProfileId`。未登录或不合格会员失败时，原 active 保持不变。
