## 规则

macOS 使用 `~/Library/Application Support/gpt-web-image`，Windows 使用 `%LOCALAPPDATA%\\gpt-web-image`。所有路径通过 Node Path API 解析；测试不得写死 POSIX 绝对路径或分隔符。Windows 不依赖 WSL/Bash。

## 验收

内部测试后进入 Windows CI 和 macOS 真机 MP-1 至 MP-7；不得用夹具结果替代真实 ChatGPT 会员、浏览器、备份和页面证据。

本轮 macOS 真实检查确认固定专用路径、归属标记和 `never-auto-delete`；隔离页面使用临时根验证创建/导入/路径检查和 Chrome 生命周期，未接触真实用户目录。最终收口提交 `0839329a21304c30d76fb7373dd54df5b3e6b3db` 的 `windows-latest` CI run `30944073691` / job `92109518018` 已绿色，覆盖 Windows 路径、锁、安装、夹具和安全合同；不能由 macOS 证据替代 Windows 用户真机。
