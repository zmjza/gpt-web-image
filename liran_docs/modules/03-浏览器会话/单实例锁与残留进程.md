# 单实例锁与残留进程

上级：[[_03-浏览器会话]]
下级：无
依赖：[[系统目录与路径规范]]、[[task-json持久化]]

---

## 场景

多个 Codex 请求、崩溃恢复或旧进程可能同时争用同一 Profile。

## 触发

任何浏览器上下文启动前，以及 doctor 检查到占用时。

## 逻辑

使用包含 pid、启动时间、Profile 路径和随机 ownerToken 的原子锁文件；活锁拒绝第二实例，死锁必须验证进程归属后才能回收。

## 状态 / 边界

不能仅凭 pid 存在就结束进程，必须核对可执行文件、Profile 参数与 ownerToken。锁清理只作用于 Skill 专用目录。
