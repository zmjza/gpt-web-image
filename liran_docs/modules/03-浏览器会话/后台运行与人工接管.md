# 后台运行与人工接管

上级：[[_03-浏览器会话]]
下级：无
依赖：[[Profile生命周期]]、[[首次可视登录]]、[[状态机与迁移]]

## 场景

正常任务需要后台运行；登录失效、验证码或安全检查需要临时显示浏览器。

## 触发

默认任务启动，或监控器发出 `needs_login/needs_human_verification`。

## 逻辑

正常使用 Headless Chrome。需要人工处理时安全保存任务和 URL、关闭后台上下文、用同一 Profile 可视重开；用户完成后继续当前任务，后续任务恢复后台模式。

## 状态 / 边界

切换不得重复提交当前提示词。不能使用自动验证码、反检测或隐藏可视验证窗口；人工长时间未完成时保持明确等待状态。
