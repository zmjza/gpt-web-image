# 后台运行与人工接管

上级：[[_03-浏览器会话]]
下级：无

## 场景

正常任务需要后台运行；登录失效、验证码或安全检查需要临时显示浏览器。

## 触发

默认任务启动，或监控器发出 `needs_login/needs_human_verification`。

## 逻辑

正常任务使用正式 Google Chrome 的专用 Profile，并以 `--start-minimized` 自动最小化到后台；不使用 `--headless`，避免真实账号链路出现额外自动化指纹。需要人工处理时安全保存任务和 URL、关闭后台上下文、用同一 Profile 可视重开；用户完成后继续当前任务，后续任务恢复后台最小化模式。

## 状态 / 边界

切换不得重复提交当前提示词。不能使用自动验证码、反检测、全局隐藏用户 Chrome 或把可视验证窗口偷偷藏起；人工长时间未完成时保持明确等待状态。普通后台任务只最小化项目专用窗口，不影响用户正在使用的其他 Chrome 窗口；台前调度模式下最多会在应用列表中保留该专用窗口入口。
