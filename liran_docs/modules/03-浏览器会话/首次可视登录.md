# 首次可视登录

上级：[[_03-浏览器会话]]
下级：无
依赖：[[Profile生命周期]]、[[语义定位与结构兼容]]

---

## 场景

专用 Profile 尚未登录 ChatGPT，必须由账号所有者亲自完成认证。

## 触发

setup 检测不到可用会话，或 Profile 被重置。

## 逻辑

以可视 Chrome 打开 ChatGPT；不输入凭据，只监控登录页、验证页和可用输入区域。检测到稳定的已登录输入区域后记录非敏感就绪标志并正常关闭。

## 状态 / 边界

验证码、密码、双因素认证只能由用户操作。仅页面跳转不算登录成功；必须以可交互输入区域和稳定会话共同确认。
