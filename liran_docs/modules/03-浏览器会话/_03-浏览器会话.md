## 职责

管理 Skill 专属 Chrome Profile、首次登录、日常后台运行、人工验证切换和单实例安全。

## 对外提供

- 已通过能力检查且可供网页适配器使用的 Playwright Page/Context。
- 登录就绪、需要人工验证、Profile 被占用等明确状态。
- 仅限本 Skill 进程与数据目录的生命周期控制。

## 关键说明

认证数据只能留在专用 Profile。后台失败转可视时必须复用同一 Profile 和任务，不得要求 Skill 获取密码，也不得结束用户日常 Chrome。

## 当前实现

`src/browser/profile.ts`、`login.ts`、`handoff.ts` 与 `profile-lock.ts` 已实现专用归属标记、正式 Chrome 可视登录、带沙箱后台复用、稳定登录判定、后台转可视计划和单实例锁。macOS 专用 Profile 的 Google 登录与 setup 就绪已验证；真实生图和人工接管仍待 T40。
