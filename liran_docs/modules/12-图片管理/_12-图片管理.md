# 12-图片管理

## 目标

在现有 Profile 管理控制台中提供单 Profile 图片查看、索引、筛选、排序、预览和本地文件操作能力。当前已完成第一次 `/goal` 的内部实现，真机与 Windows 用户验收仍未完成。

## 范围

- 单 Profile 选择和严格图片隔离。
- 受控输出目录扫描、ImageRecord 索引、任务/项目归属和增量刷新。
- 时间、项目、任务、类型、格式、尺寸、状态和关键词组合筛选。
- 时间、项目活动、文件名、大小和尺寸排序。
- 项目/任务/日期分组、缩略图懒加载、详情预览和本地文件操作。
- 加载、空态、无结果、缺失、损坏、权限、扫描失败、生成中和生成失败状态。
- 本地管理 API、现有 UI 壳接入、内部测试、macOS 真机、Windows CI 和 Windows 用户验收准备。

## 不在本轮

- 不删除图片，不做云端同步，不读取 Chrome 认证数据。
- 不创建独立 demo；图片管理只接入现有 Profile UI 壳。
- 不把静态 UI 数据或本地夹具结果写成真实业务证据。

图片管理 Stitch Screen 已收到并下载，完成原始产物接收、实例级复修、真实 UI/API 接线和自动化验证。`src/images/manager-*.ts` 实现索引、扫描、归属、查询、缩略图和文件操作；`src/manager/server.ts` 和 `src/manager/public/app.js` 完成同源本地接线。生成中/失败任务即使没有图片文件也会以不可预览状态记录呈现；页面和 API 都不提供图片删除。
