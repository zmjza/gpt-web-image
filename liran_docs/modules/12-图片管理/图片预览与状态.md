# 图片预览与状态

## 目标

提供稳定的缩略图浏览、原图预览、详情信息和可执行文件操作，并完整呈现异常状态。

## 展示与操作

- 网格和列表视图，缩略图懒加载，必要时分页或无限滚动。
- 详情显示文件名、时间、Profile、项目/任务、类型、尺寸、格式、大小和状态。
- 支持原图查看、放大、复制路径、打开目录、下载/导出和查看任务。
- 不提供删除或批量删除。

## 状态

loading、empty、no_results、scan_error、directory_missing、permission_denied、file_missing、file_corrupt、generating、generation_failed、success。

## 规划文件

`src/images/manager-preview.ts`、`src/manager/public/`、`tests/manager/image-manager-ui.test.ts`。
