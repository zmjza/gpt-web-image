# 图片查询与筛选

## 目标

在单 Profile 索引上提供组合筛选、关键词搜索、排序和最近项目分组。

## 查询维度

- 时间范围：今天、7 天、30 天、90 天、自定义和全部。
- 项目/任务：项目、任务批次、未归类。
- 生成类型：文生图、参考图改图、连续修改和其他。
- 文件：格式、横/竖/方图、尺寸或宽高比。
- 状态：已完成、生成中、失败、文件缺失和文件损坏。
- 关键词：文件名、项目名、任务名、提示词摘要和备注。

## 排序与分组

默认生成时间倒序；支持旧到新、项目最近活动、文件名、大小和尺寸。分组支持项目、任务批次、日期和不分组，默认最近项目优先。
