# 图片索引与扫描

## 目标

只扫描选中 Profile 的受控输出根目录，建立可增量更新的图片索引，不读取 Chrome 认证数据。

## 规则

- 查询上下文必须带 `profileId`、规范化根目录和扫描版本。
- 校验根目录归属、符号链接、中文/空格路径、macOS 路径和 Windows 盘符。
- 识别支持的图片格式，读取尺寸、大小、修改时间和可选任务元数据。
- 文件缺失、损坏、权限错误和目录不存在都记录为可展示状态，不使整批扫描崩溃。
- 首次扫描、手动重扫、生成完成刷新和目录迁移后重索引都必须可观测。

## 规划文件

`src/images/manager-index-store.ts`、`src/images/manager-scanner.ts`、`src/images/manager-model.ts`、`src/images/manager-query.ts`、`tests/images/manager-index.test.ts`、`tests/images/manager-domain.test.ts`。

## 当前状态

内部实现和自动化验证通过，待 macOS 真机、Windows CI 和 Windows x64 用户验收。当前证据来自真实索引代码、路径安全测试、API 契约测试和三视口页面检查；不得把这些内部证据误写成真实 ChatGPT 生成图片验收。
