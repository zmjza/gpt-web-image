# 图片管理微观任务拆分

本表为 T62 起的完整规划来源。T62–T77 已完成图片管理 UI 壳承接、真实本地 API 接线、索引/查询/文件操作和自动化验证；T78–T79 只保留 macOS、Windows CI 与 Windows x64 用户验收，不得把内部夹具或页面检查写成真机通过。

| 任务组 | 微观任务 |
|---|---|
| 导航与上下文 | 导航入口、路由/视图状态、Profile 选择器、单 Profile 隔离、空 Profile 状态 |
| 索引与扫描 | 根目录解析、路径安全、首次扫描、增量扫描、重新扫描、迁移后重索引、索引持久化 |
| 数据与归属 | ImageRecord、ImageIndex、任务关联、项目归类、未归类回退、状态枚举 |
| 查询 | 时间、项目、任务、类型、格式、尺寸、方向、状态、关键词组合筛选；默认时间倒序和其他排序 |
| 分组与性能 | 最近项目、任务批次、日期分组；缩略图、懒加载、分页/无限滚动、大图库性能 |
| 预览与文件操作 | 详情、原图、缩放、复制路径、打开目录、下载/导出；禁止删除 |
| 状态与 API | loading/empty/no-results/error/missing/corrupt/generating/failed/success；本地 API 和脱敏错误码 |
| UI 壳接入 | 外部产物登记、HTML 事实盘点、导航映射、真实 API/type/event 接线、初次接收检查、实例级细节复修 |
| 验证与收口 | 单元、契约、集成、文件系统、macOS 真机、Windows CI、Windows x64 用户验收、避坑回写 |
