## 场景

用户直接说“生成图片”“画 4 张海报”或“按参考图改图”，没有输入技能名。

## 触发

Codex 根据 Skill description 识别生成、改图、参考图、批量图片和连续修改意图。

## 逻辑

元数据使用名称 `gpt-web-image`、显示名“GPT 网页生图”，默认允许隐式调用；命中后加载 SKILL.md，先解析输入，再决定直接执行或歧义确认。

## 状态 / 边界

不得把查看、分析、压缩或仅讨论图片的请求识别成生图。Skill 变更未被发现时允许提示重启 Codex，但不能伪造已安装状态。

## 当前实现

已创建 `.agents/skills/gpt-web-image/SKILL.md` 与 `agents/openai.yaml`，并通过本地元数据测试。当前只完成发现与触发契约，尚未接入控制脚本、浏览器或真实 ChatGPT。
