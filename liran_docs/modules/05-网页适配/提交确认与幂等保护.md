# 提交确认与幂等保护

上级：[[_05-网页适配]]
下级：无
依赖：[[TaskRecord与任务ID]]、[[新会话与连续修改]]、[[中断恢复与结果不确定]]

---

## 场景

网页提交可能因网络、页面延迟或进程中断处于“点击了但不知道是否成功”的状态。

## 触发

发送提示词、补图提示或恢复未确认提交。

## 逻辑

提交前保存消息基线和 attemptId；提交后以输入区状态、新增用户消息及内容指纹确认。只有明确未提交证据才允许重试；已存在或不确定则禁止二次提交。

## 状态 / 边界

不能把网络超时等同于未提交。内容指纹只用于本地相关性，不注入提示词，不保存敏感 DOM 或认证信息。
