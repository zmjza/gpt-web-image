## 场景

ChatGPT 网页文案、层级或 CSS 变化时仍需可靠识别输入、消息、错误和下载入口。

## 触发

页面就绪检查、提交、回复绑定、下载和人工验证检测。

## 逻辑

定位优先级为角色/可访问名称、稳定标签和消息关系、可配置文本语义，最后才是经过夹具验证的局部结构。适配器返回证据和置信分类，不直接猜测。

## 状态 / 边界

随机 CSS 类和屏幕坐标不能作为唯一依据。关键控件缺失或多个候选冲突时安全停止并触发脱敏诊断。
