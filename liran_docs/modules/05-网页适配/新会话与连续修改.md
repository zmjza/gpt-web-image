# 新会话与连续修改

上级：[[_05-网页适配]]
下级：无
依赖：[[Profile生命周期]]、[[TaskRecord与任务ID]]

---

## 场景

新文字生图/参考图改图需要隔离会话；对已有结果继续修改需要保留上下文。

## 触发

任务获得执行权并已确认登录可用。

## 逻辑

generate 和独立 edit 创建新 ChatGPT 对话并保存 URL；refine 根据源 taskId 复用原会话并记录新的消息基线。参考图在提交前完成上传确认。

## 状态 / 边界

原会话缺失或无权限时不得静默新建并假装连续修改，必须报告上下文不可恢复并要求明确选择新任务策略。
