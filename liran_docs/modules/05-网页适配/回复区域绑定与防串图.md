# 回复区域绑定与防串图

上级：[[_05-网页适配]]
下级：无
依赖：[[提交确认与幂等保护]]、[[图片发现与稳定判定]]

---

## 场景

ChatGPT 对话可能已有历史图片，连续修改也可能产生多轮助手回复。

## 触发

本次用户消息确认出现后，等待对应的新助手回复。

## 逻辑

记录提交前消息/图片集合，将紧随本次用户消息的助手 turn 绑定为 responseAnchor；监控、图片发现和下载只能在该 anchor 内进行，并保存可恢复的语义标识。

## 状态 / 边界

无法唯一绑定时进入结构异常或结果不确定，禁止退化为扫描整页最新图片。历史资源永远不能计入目标数量。
