## 职责

通过公开网页交互创建或复用 ChatGPT 对话，提交请求，建立消息基线并把任务绑定到唯一助手回复区域。

## 对外提供

- 会话 URL、提交确认结果、绑定回复句柄和页面语义快照。
- 对登录页、验证页、错误页和结构变化的分类结果。

## 关键说明

不依赖随机 CSS 类，不调用私有接口。提交结果不确定时先寻找本次用户消息证据；证据不足则停止，绝不盲目二次提交。

## 当前实现

`src/chatgpt/` 已实现新会话/连续修改策略、可访问语义定位、提交指纹与三态确认、邻接回复绑定及 Playwright 网页流程。可控夹具验证了历史图隔离、排队、逐图和错误分类；真实 ChatGPT DOM 兼容性待 T40。
