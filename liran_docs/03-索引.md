## 阅读与开发顺序

按 `04-开发追踪.md` 的拓扑顺序推进：跨平台与契约基础 → Profile 注册表与目录 → 浏览器会话/会员检测 → 本地服务与页面 → 生图绑定 → 备份迁移 → 自动化测试 → macOS 真机与 Windows CI。
