# 数据字典

> 字段是首版契约。代码实现前可细化类型，但不得改变安全与状态不变量；变更需同步本文件、API、测试和模块文档。

## 敏感等级

| 等级 | 含义 | 持久化规则 |
|---|---|---|
| S0 | 非敏感状态与计数 | 可写 task.json、事件和日志 |
| S1 | 用户内容或本地路径 | 仅为任务恢复持久化；诊断输出需最小化 |
| S2 | 会话关联信息 | 会话 URL 可写 task.json，但不得公开输出完整查询参数 |
| S3 | 密码、Cookie、令牌、认证头 | 禁止进入 task.json、事件、日志和仓库 |

## TaskState

| 值 | 含义 | 可进入条件 |
|---|---|---|
| `initializing` | 初始化任务 | TaskRecord 已持久化 |
| `needs_login` | 未登录 | 页面证据指向登录入口 |
| `ready` | 页面可提交 | 输入区域可交互 |
| `submitted` | 提交已确认 | 新用户消息证据存在 |
| `queued` | 网页端等待 | 助手响应尚未开始但有排队证据 |
| `generating` | 正在生成 | 绑定回复出现活动证据 |
| `partial` | 已发现部分结果 | 至少一个稳定或成功图片，仍在活动 |
| `stabilizing` | 等待结果稳定 | 生成活动趋于结束，候选需稳定 |
| `downloading` | 下载原图 | 稳定候选进入下载器 |
| `validating` | 校验文件 | 临时文件已完整写入 |
| `succeeded` | 达到目标且全部合格 | 文件与事件核对一致 |
| `partial_success` | 有合格结果但未达目标 | 补图结束或不可继续 |
| `failed` | 明确失败且无可交付结果 | 分类错误证据充分 |
| `timed_out` | 超时终止 | 无活动或硬上限命中 |
| `cancelled` | 用户取消 | 取消已安全落盘 |
| `recovering` | 正在重建状态 | resume 读取非终态记录 |
| `needs_human_verification` | 需要用户处理验证 | 验证页/验证码证据 |
| `structure_changed` | 网页结构不符合不变量 | 关键语义缺失/冲突 |
| `result_uncertain` | 无法证明提交或结果归属 | 禁止自动重提 |

# 图片管理数据

> 以下结构已在 `src/images/manager-*.ts` 和对应测试中落地；真机验收状态仍以 `09-真机实测.md` 为准。

## ImageRecord

| 字段 | 类型 | 说明 |
|---|---|---|
| imageId | string | `profileId + 根目录内相对路径` 的 SHA-256 稳定 ID；任务状态占位额外包含状态标识 |
| profileId | string | 唯一归属 Profile，必填 |
| absolutePath | string | 规范化本地路径，不得越出 Profile 输出根目录 |
| fileName | string | 文件名 |
| generatedAt | string | 生成时间；来源不足时标注待确认 |
| projectId/projectName | string/null | 项目归属或未归类 |
| taskId | string/null | 关联 TaskRecord |
| generationType | enum | text_to_image、image_to_image、refine、other |
| format | string | 通过真实文件解码得到；无文件任务占位为空字符串 |
| width/height | number/null | 图片尺寸，损坏文件可为空 |
| byteSize | number/null | 文件大小 |
| status | enum | completed、generating、failed、missing、corrupt |
| thumbnailPath | string/null | 扫描时为 null，预览请求时按需生成 |
| contentHash | string/null | 真实图片文件的 SHA-256；缺失、损坏和任务占位为 null |

## ImageIndex、ProjectGroup、ImageFilter、ImageSort、ImageStatus

- `ImageIndex`：`profileId`、索引版本、扫描时间、根目录、记录集合、缺失/损坏统计。
- `ProjectGroup`：项目或任务批次标识、显示名、最近活动时间、图片数量、未归类标记。
- `ImageFilter`：Profile、时间范围、项目/任务、类型、格式、尺寸/方向、状态、关键词。
- `ImageSort`：generatedAt_desc（默认）、generatedAt_asc、projectActivity、fileName、byteSize、dimensions。
- `ImageStatus`：页面状态为 loading、empty、no_results、scan_error、directory_missing、permission_denied；记录状态为 completed、generating、failed、missing、corrupt。无图片文件的进行中/失败任务由 `task.json` 生成不可预览占位记录。
