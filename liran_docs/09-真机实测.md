## 跑通总规则

1. 每项必须以真实触发、真实状态、真实文件和真实反馈为证据。
2. 图片只有在本地文件存在、可解码且与 `image_ready` 路径一致时才算交付成功。
3. 第一张图片必须在整批 terminal 事件之前显示，不能用最终统一清单冒充实时回显。
4. 截图不能代替原图；生成成功但下载失败不能算完整成功。
5. 任何登录、验证码或安全验证均由账号所有者操作，Codex 不获取凭据。
6. 当前步骤全部通过后才能进入下一步；失败时停在当前步骤修复复测。
7. 后续修改破坏已通过项时必须撤销对应 `✅` 并重新实测。
8. Windows 用户验收分支不填写 Codex 真机 `✅`；收到用户明确反馈后记录“用户验收通过”。
