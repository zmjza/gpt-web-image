# 术语表

> 规划代码命名是实现约定，不代表对应符号已存在。

| 术语 | 定义 | 同义词/别名 | 规划代码命名 |
|---|---|---|---|
| GPT 网页生图 | 本项目提供的 Codex Skill | 网页版生图桥接器 | `gpt-web-image` |
| Skill | Codex 可隐式/显式调用的工作流目录 | 技能 | `SKILL.md` |
| 专用 Profile | 只供本 Skill 使用的 Chrome 用户数据目录 | 独立浏览器档案 | `profileDir` |
| 可视模式 | 显示 Chrome 窗口，供登录或人工验证 | Headed | `headed` |
| 后台模式 | 正常任务使用的无窗口 Chrome | Headless | `headless` |
| 任务 | 一次生成、改图或连续修改请求 | 生图任务 | `TaskRecord` |
| 任务 ID | 跨进程识别任务的唯一且路径安全标识 | taskId | `taskId` |
| 新任务 | 新建 ChatGPT 对话的生成或独立改图 | 独立任务 | `generate` / `edit` |
| 连续修改 | 复用原 ChatGPT 对话修改已有结果 | refine | `refine` |
| 提交基线 | 提交前的消息、图片和时间事实 | baseline | `SubmissionBaseline` |
| 回复锚点 | 与本次用户消息对应的唯一助手回复区域 | responseAnchor | `ResponseAnchor` |
| 多信号判定 | 组合 DOM、语义、图片和网络旁证判断状态 | 状态融合 | `EvidenceSnapshot` |
| 活动时钟 | 仅被相关页面变化刷新的无活动计时 | inactivity clock | `lastActivityAt` |
| 稳定图片 | 已加载、尺寸有效、指纹在窗口内不变的候选 | image candidate | `StableImageCandidate` |
| 原图 | 网页下载入口或页面已暴露资源得到的文件 | original | `originalPath` |
| 显示预览 | 原图不能显示时生成的 PNG 副本 | preview | `previewPath` |
| 图片就绪事件 | 图片校验成功后立即通知 Codex 回显的事件 | image_ready | `ProgressEvent` |
| 部分成功 | 至少一张成功但未达到目标数量 | partial success | `partial_success` |
| 结果不确定 | 无法证明提交/绑定/恢复状态，不允许猜测 | uncertain | `result_uncertain` |
| 结构异常 | 网页关键语义不满足，停止盲点操作 | page changed | `structure_changed` |
| 诊断资料 | 脱敏截图、快照、Trace 与错误信息 | diagnostics | `DiagnosticRecord` |
| 真机验收 | 在真实 Chrome、账号与 Codex 宿主中走完整链路 | E2E | `realTest` |
